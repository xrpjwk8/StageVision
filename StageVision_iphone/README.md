# StageVision iPhone · iPad MVP

무대의 너비와 깊이를 정하고, 무대 평면도를 터치해 무용수의 **시작 위치를 수동으로 지정**하는 SwiftUI 앱입니다.

## 실행

1. `StageVision_iphone.xcodeproj`을 Xcode에서 엽니다.
2. `StageVision_iphone` 스킴을 선택합니다.
3. Xcode 상단에서 연결한 iPhone 또는 iPad를 선택해 실행합니다. 실제 기기 설치 시 Xcode의 Signing & Capabilities에서 개발 팀을 선택해야 할 수 있습니다.

현재 프로젝트의 Deployment Target은 iOS/iPadOS 26.2입니다. 하나의 앱 타깃이 iPhone과 iPad를 모두 지원합니다. iPad의 넓은 화면에서는 평면도와 설정 패널이 나란히 표시됩니다. RoomPlan 스캔은 LiDAR 지원 iPhone 또는 iPad에서만 사용할 수 있습니다. 다른 기기에서는 무대 크기를 직접 조정할 수 있습니다.

## 사용 흐름

1. 무대 너비와 깊이를 0.1m 단위로 조정하거나 `무대 스캔 시작`을 누릅니다.
2. 스캔 중 카메라 화면에서 감지된 바닥 외곽은 주황색, 바닥 위 1m 좌표 격자는 민트색으로 확인합니다. 비정형 바닥에서는 감지된 다각형 내부에 격자가 표시됩니다.
3. 스캔 결과가 나오면 바닥 크기를 확인하고 적용합니다. 감지한 바닥의 긴 변을 너비로 사용하므로, 무대 방향이 다르면 `너비와 깊이 바꾸기`를 누릅니다.
4. 위험 구역을 적용할 가장자리를 앞·좌·우·뒤에서 각각 선택하고 폭을 1.0m 또는 1.5m로 설정합니다.
5. 평면도의 주황색 영역이 선택한 위험 구역입니다. 평면도를 터치하면 시작 위치 마커와 좌표가 나타납니다. X는 무대 왼쪽에서의 거리, Y는 무대 앞에서 뒤쪽으로의 거리입니다. 시작 위치가 선택한 위험 구역이면 경고가 나타납니다.

RoomPlan은 실내 공간의 바닥을 감지합니다. 개방된 무대에서는 스캔 결과가 실제 공연 가능 구역과 다를 수 있으므로 무대 경계를 확인하고 수동으로 조정하세요. 이 버전은 시작 위치만 기록하며 이동 중 위치 추적과 음향 안내는 포함하지 않습니다.
